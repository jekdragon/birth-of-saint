## Full Description

### ✝ Рождение святого (Birth of the Saint)

A **biblical horror roguelike** inspired by Vampire Survivors, built entirely in Python with pygame-ce.

### 🎮 Features
- **WASD movement** with auto-attack combat
- **9 unique weapons**: Whip, Holy Fire, Halo, Rosary, Lightning, Prayer Wave, Incense, Cross, Bell
- **10 passive upgrades**: Faith, Grace, Zeal, Protection, Prayer, Blessing, Envy, Magnet, Armor, Providence
- **7 weapon evolutions**: Combine weapons with passives for devastating upgrades
- **11 enemy types**: Neophytes, Acolytes, Heretics, Demons, Fanatics, Ghosts, Gargoyles, Shades, Cultists, and bosses (Antichrist, False Pope)
- **5 playable characters**: Warrior, Paladin, Inquisitor, Pilgrim, Monk — each with unique bonuses
- **2 maps**: Arena (4 biome rings) and Cathedral (corridors, chapels, columns)
- **5 Arcana modifiers**: Change game rules between runs for replayability
- **8 Relics**: Collectible items on the map for passive bonuses
- **Meta-progression**: Gold → PowerUp shop between runs, 6 upgrades, 5 achievements
- **15-minute sessions**: Reaper spawns at 15 minutes — survive or die!
- **Procedural pixel art**: 16x16 sprites generated at runtime
- **Procedural music**: Ambient soundtrack generated as WAV

### 🕹️ Controls
- **WASD** — Move
- **SPACE/ENTER** — Select in menus
- **C** — Character select
- **M** — Map select
- **R** — Restart after game over
- **ESC** — Back to menu

### 🛠️ Built With
- Python 3.12+
- pygame-ce (Community Edition)
- pygbag (WebAssembly build)

### 📖 Story
You are a holy warrior in a world overrun by biblical horrors. Fight through waves of corrupted faithful, demons, and the Antichrist himself. Collect divine weapons, upgrade your faith, and survive the 15-minute trial. The False Pope awaits in the Cathedral...

### 🏆 Achievements
- **Первый шаг** — Reach wave 3
- **Ветеран** — Reach wave 7
- **Убийца боссов** — Kill a boss
- **Святой** — Survive 10 minutes
- **Легенда** — Survive 15 minutes

### 💰 Meta-Progression
Earn gold by killing enemies. Between runs, visit the Lobby to buy permanent upgrades:
- **Might** — +10% damage per level
- **Speed** — +8% movement speed
- **Sturdiness** — +10 max HP
- **Greensight** — +15% XP gain
- **Greed** — +10% gold drops
- **Luck** — +5% crit chance per level

### 🎵 Technical Details
- All art is procedurally generated (no external assets)
- Music is synthesized at runtime
- Game state saves to JSON between sessions
- Web build via pygbag (WebAssembly)
