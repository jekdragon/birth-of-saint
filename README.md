# Рождение святого

Roguelike-survivors в стиле Vampire Survivors. Python + pygame-ce.

## Запуск

```bash
pip install pygame-ce
python main.py
```

## Запуск в браузере (pygbag)

```bash
pip install pygbag
pygbag --build main.py
# Открыть http://localhost:8000
```

## Управление

- **WASD / Стрелки** — движение
- **1 / 2 / 3** — выбор предмета при левелапе
- **R** — реролл при левелапе
- **ENTER** — старт в меню
- **C** — выбор персонажа

## Персонажи

| Персонаж | Оружие | Особенность |
|----------|--------|-------------|
| Воин | Святой кнут | +10% урон каждые 10 уровней |
| Паладин | Орбитальная аура | +25% pickup range |
| Инквизитор | Священный огонь | +1 снаряд ко всему |

## Оружие

6 типов с апгрейдом до 8 уровня. 4 эволюции.

## Стек

- Python 3.12+
- pygame-ce
- pygbag (WebAssembly)
