# КОНЦЕПЦИЯ: Редизайн интерфейса "Рождение святого"

> Дата: 2026-08-02
> Статус: Утверждено
> Авторы: Stepan + Софья

---

## 1. ВИДЕНИЕ

Игра "Рождение святого" — это Vampire Survivors клон в сеттинге библейского хоррора с тёмным фэнтези. Текущий интерфейс функционален, но неорганичен: экраны не связаны визуально, переходы однообразные (только fade), кнопки статичные, фоны мёртвые.

**Цель:** сделать интерфейс живым, атмосферным и единым. Каждый экран должен ощущаться как часть одного мира — мира камня, крови, золота и свечей.

---

## 2. ПРОБЛЕМЫ ТЕКУЩЕГО UI

### 2.1. Навигация
- **Title Menu:** 7 кнопок в столбик — перегружено. ПЕРСОНАЖ, КАРТА, ПРОФИЛИ — отдельные сцены, хотя логически это части лобби.
- **CharSelect + StageSelect:** отдельные экраны, хотя должны быть встроены в лобби как табы.
- **Bestiary + Codex:** отдельные сцены, хотя это один экран с двумя вкладками.
- **Settings:** открывается из разных мест по-разному, нет единого паттерна.

### 2.2. Визуал
- Кнопки не анимированы (нет stagger-появления, нет hover-смещения).
- Переходы между экранами — только fade 0.3s.
- Фоны статичные (кроме splash и menu).
- Нет единого стиля — каждый экран рисует UI по-своему.
- Шрифт — дефолтный pygame, не пиксельный.

### 2.3. Техническое
- Каждый экран сам рисует свои кнопки, панели, слоты.
- Нет общей компонентной библиотеки.
- Цвета захардкожены в каждом файле отдельно.
- Нет системы анимаций (tween, stagger, easing).

## 3. НОВАЯ АРХИТЕКТУРА

### 3.1. Навигация (упрощённая)

```
Splash → Title (3 кнопки) → Lobby (6 табов) → Game → Game Over → Lobby
```

**Title Menu:** ИГРАТЬ / НАСТРОЙКИ / ВЫХОД (вместо 7 кнопок)
**Lobby:** Герои / Карты / Магазин / Кодекс / Рекорды / Прогресс (всё-в-одном)
**Settings:** оверлей, открывается из любого места

### 3.2. Компонентная система

Единая библиотека `ui_components.py` с 19 классами:

| Компонент | Назначение |
|-----------|------------|
| UIElement | Базовый класс (rect, hover, focus, lifecycle) |
| UIButton | 4 стиля (primary/default/danger/ghost), 4 состояния |
| UIPanel | Каменная панель с рамкой и тенью |
| UITabBar | Горизонтальные вкладки с навигацией |
| UICard | Карточка выбора (персонаж, оружие, аркана) |
| UISlider | Ползунок настроек |
| UIProgressBar | Анимированная полоса прогресса |
| ToastManager | Всплывающие уведомления |
| UIConfirmDialog | Диалог подтверждения |
| UIDialogueBox | Typewriter-текст для описаний |
| UIParticleSystem | Конфигурируемые частицы для фонов |
| UIHoverPointer | Пиксельный указатель при hover |
| UIHeartBar | Счётчик сердечек (HP) |
| UIHotbar | Быстрые слоты с нумерацией |
| UITooltip | Всплывающая подсказка с задержкой |
| PixelateTransition | Пиксельный fade-переход |
| WipeTransition | Переход-штора |

### 3.3. Дизайн-система (`ui_theme.py`)

Единая точка правды для всех цветов и размеров:

**Палитра:**
- Фон: near-black (#0a0e14)
- Камень: тёмный purple-grey (#1c1820)
- Кровь: тёмно-красный (#8c1414)
- Золото: gold leaf (#ffd700)
- Священный: cyan (#00bfff)
- Текст: white (#ffffff) / grey (#b4b4b4) / dim (#505050)

**Редкость предметов:** grey → green → blue → purple → gold

**Типографика:** 7 размеров шрифта (12-56px), кэшированные

### 3.4. Анимации (`animation.py`)

- 9 easing-функций (linear, quad, cubic, elastic, bounce, sine)
- Tween — анимированное значение от A до B
- StaggerAnimator — последовательное появление элементов
- ScalePunch — пульсация при hover/select
- Heartbeat — lub-dub пульсация логотипа
- Transition engine — fade, slide, crossfade, fade-to-red
- Parallax — параллакс фона от мыши

## 4. КЛЮЧЕВЫЕ РЕШЕНИЯ ИЗ PDF-СПЕЦИФИКАЦИИ

Документ "Разработка спецификации интерфейса игры" (Gemini, 01.08.2026) добавил 10 решений:

1. **Virtual Canvas + Integer Scaling** — рендер на 480x270, потом scale x2. Настоящий пиксель-арт лук.
2. **Пиксельный шрифт** — antialias=False + .ttf (Press Start 2P / Silkscreen).
3. **9-Slice Scaling** — рамки панелей из спрайтов вместо draw.rect.
4. **Счётчик сердечек** — discrete HP: каждое сердечко = N HP.
5. **Hotbar + Stack Count** — быстрые слоты с нумерацией и количеством.
6. **Пиксельный указатель** — меч/стрелка рядом с текстом при hover.
7. **Pixelate Fade** — переход через downscale → upscale.
8. **Wipe Transition** — пиксельная штора.
9. **Tooltip с задержкой** — 0.5с пауза, затем всплывающее окно.
10. **Limited Palette** — PICO-8 (16 цветов) или JUGGLER 64.

**НЕ адаптируем:** Integer Scaling на весь экран (у нас 1024x768), .ttf шрифты (pygame default OK для MVP).

## 8. ПРИНЦИПЫ ДИЗАЙНА

1. **Единство стиля** — все экраны используют одну палитру, одни шрифты, одни компоненты.
2. **Живой UI** — частицы, параллакс, пульсация, анимации. Ничего не должно быть статичным.
3. **Органичные переходы** — каждый переход уникален, длится 0.2-0.8с, с easing.
4. **Пиксельная точность** — без anti-aliasing, на пиксельной сетке.
5. **Звук на каждое действие** — hover, click, back, confirm.
6. **Stagger-появление** — элементы появляются по одному с задержкой 0.08с.
7. **Hover-feedback** — смещение + подсветка + pointer.
8. **Кэширование** — процедурные текстуры генерируются один раз.
9. **WASM-совместимость** — только pygame.draw, никаких внешних библиотек.
10. **Не ломать gameplay** — Game class не трогаем, только UI-обёртки.
